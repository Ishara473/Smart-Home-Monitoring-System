# Mobile Application

This directory will contain the mobile application client built with **React Native** and **Expo**.

## Scope & Functionality

- **Multi-Floor Interactive Dashboard**: Abstract grid mapping overlay on floor plans with interactive device controls.
- **Heterogeneous Device Support**: Standard single power outlets, multi-switch gang units, safety-critical timer slots (e.g., irons), preset lighting schedules, and security camera feeds.
- **Reactive UI**: Real-time status sync (`ON`, `OFF`, `ERROR`, `DISCONNECTED`).
- **Device Analytics & Reporting**: Usage history and data metrics visualizer.
